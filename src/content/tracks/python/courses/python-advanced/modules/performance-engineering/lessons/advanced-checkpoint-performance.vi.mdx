## Checkpoint — giải cứu N+1

`db` ghi lại mọi lần `db.query(sql, params)`. Bản ngây thơ tạo một truy vấn CHO
MỖI user (N+1). Hãy gộp lại:

- `fetch_user_orders(user_ids, db)` trả về `{user_id: [{'id':…, 'total':…}, …]}`
- với **tối đa 2 truy vấn** tổng cộng (bất kể số user)
- danh sách order của từng user giữ nguyên thứ tự dòng mà db trả về

Đây chính là hình dạng bạn sẽ gặp lại trong module database — học ở đây như
một pattern hiệu năng, áp dụng ở đó như SQL.
