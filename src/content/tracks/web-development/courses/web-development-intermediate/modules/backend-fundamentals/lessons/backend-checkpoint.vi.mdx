Checkpoint này dựng lại các bộ phận chuyển động của backend ở dạng chạy được: router bạn viết tay, pipeline, và tư thế validation — chấm dưới dạng logic thuần, cùng lập luận mà Express tự động hóa.

## Server chỉ là các hàm

HTTP server của Node là một hàm biến request thành response, và mọi thứ bạn
đã luyện — routing, middleware, validation, hình dạng lỗi — là composition
của hàm đó. Checkpoint gỡ framework ra thêm một lần nữa để pattern thuộc về
bạn, chứ không phải của Express. Khi sau này gặp Express, Fastify, hay route
handler của một framework đầy đủ, bạn sẽ nhận ra những người bạn cũ.

## Từ handler thành thói quen

Các tình huống trong checkpoint nén lại những gì một service thật làm mỗi
request: đọc request an toàn, quyết định nó nghĩa là gì, xác thực ý nghĩa đó,
đụng vào trạng thái, và trả lời bằng mã trạng thái trung thực. Khi sau này
thêm framework, những nước đi đó vẫn vậy — Express chỉ cho chúng cú pháp thân
thiện hơn. Đỗ ở đây nghĩa là pattern — không phải API — đã thuộc về bạn.
