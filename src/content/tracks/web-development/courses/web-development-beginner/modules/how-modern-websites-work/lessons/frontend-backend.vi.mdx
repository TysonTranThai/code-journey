Bạn đã xây dựng **frontend** — code chạy trong trình duyệt. Giờ hãy gặp phần còn lại của cỗ máy.

## Hai nửa của mọi trang web

- **Frontend (phía client):** HTML, CSS, JavaScript — được tải xuống _trình duyệt của người dùng_ và thực thi ở đó. Mọi thứ từ Module 1–4 sống ở đây.
- **Backend (phía server):** code trên một server, phản hồi các request, áp dụng các quy tắc, và sở hữu dữ liệu. Người dùng không bao giờ thấy code này.

## Một cú bấm, từ đầu đến cuối

Khi bạn bấm "Mua hàng":

1. Trình duyệt gửi một **HTTP request** — "POST /checkout" kèm giỏ hàng của bạn.
2. **Server** nhận nó. Code backend chạy: kiểm tra phiên, xác thực giỏ hàng, tính thuế.
3. Server hỏi **cơ sở dữ liệu** — "lưu đơn hàng này" — và chờ.
4. Server gửi trả lại một HTTP **response** — status, và thường là JSON.
5. JavaScript của trình duyệt render trang xác nhận.

Tất cả điều đó trong vài trăm mili giây, hàng nghìn lần mỗi giây, khắp nơi trên thế giới.

## Code Journey tự nó khớp vào đâu

Khi bạn bấm **Run** trên một thử thách: trình duyệt của bạn (frontend) gửi code của bạn đến một server Code Journey (backend), server lưu công việc và trao nó cho một cỗ máy thực thi được khóa chặt, rồi trả về một phán quyết mà trình duyệt của bạn hiển thị. Bạn đã đang dùng một ứng dụng full-stack suốt thời gian qua — giờ bạn có thể gọi tên từng bộ phận của nó.

## Vì sao sự tách bạch quan trọng

Frontend có thể bị _sửa đổi_ bởi bất kỳ ai (mở DevTools — mọi giá trị trong đó đều là của bạn để xem xét). Nên niềm tin nằm trên server: mật khẩu, giá cả, quyền hạn. Bất kỳ site nào tin tưởng trình duyệt trong các quyết định quan trọng sẽ bị phá trong vòng vài phút. Ý tưởng đơn lẻ này giải thích phần lớn các quyết định bảo mật bạn sẽ từng gặp.

## Bạn đã học được gì

- Frontend chạy trong trình duyệt; backend chạy trên server
- Chu trình request: request → server → database → response → render
- Code Journey tự nó là một app full-stack mà bạn đã đang dùng
- Trình duyệt là lãnh thổ không tin được — các kiểm tra thật xảy ra phía server

**Tiếp theo:** giao thức mang tất cả những thứ đó — HTTP.
