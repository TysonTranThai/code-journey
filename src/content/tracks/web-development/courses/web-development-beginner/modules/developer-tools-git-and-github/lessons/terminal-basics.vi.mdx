Trình quản lý tệp đồ họa hiển thị các thư mục như những biểu tượng. **Terminal** hiển thị cùng một hệ tệp dưới dạng văn bản — và cho bạn hành động trên nó bằng những lệnh ngắn. Nó trông đáng sợ nhưng thực ra là công cụ dễ đoán nhất bạn từng dùng.

## Dấu nhắc và thư mục làm việc

Mỗi terminal có một **thư mục làm việc** — thư mục bạn đang "ở trong". `pwd` (print working directory) cho biết bạn đang ở đâu:

```text
$ pwd
/Users/ada/projects
```

## Năm lệnh quan trọng

```text
pwd               # tôi đang ở đâu?
ls                # liệt kê tệp ở đây
cd my-project     # đổi thư mục — vào my-project
cd ..             # lùi lại một cấp
mkdir new-site    # tạo một thư mục mới
```

CMD/PowerShell của Windows dùng `dir` thay cho `ls`; mọi thứ khác ở đây hoạt động như nhau.

## Đường dẫn: tuyệt đối so với tương đối

- **Tương đối** (`cd projects`) — tính từ nơi bạn đang đứng
- **Tuyệt đối** (`cd /Users/ada/projects`) — tính từ gốc của đĩa

`.` nghĩa là "thư mục này" và `..` nghĩa là "thư mục cha" — `cd ..` leo lên một cấp, `./index.html` trỏ vào một tệp tại đây.

## Tạo tệp và chạy chương trình

```text
touch notes.txt       # tạo một tệp rỗng
node script.js        # chạy một chương trình với một đối số
git status            # một chương trình khác: Git (bài học sau)
```

Mẫu luôn luôn là: tên chương trình, rồi các đối số. Bạn đã biết hình dạng này từ `console.log` — terminal chỉ là phiên bản lớn hơn.

## Bạn đã học được gì

- Terminal là góc nhìn văn bản của cùng một hệ tệp
- `pwd`, `ls`, `cd`, `mkdir`, `touch`
- Đường dẫn tương đối so với tuyệt đối; `.` và `..`
- Mọi lệnh đều là một chương trình cộng với các đối số

**Tiếp theo:** kiểm soát phiên bản — vì sao mọi dòng code đều xứng đáng có nút hoàn tác.
