Một **mảng (array)** là một danh sách có thứ tự dưới một cái tên:

```js
const skills = ["HTML", "CSS", "JavaScript"];
```

## Truy cập theo chỉ số — từ số 0

```js
skills[0]; // "HTML"       phần tử ĐẦU TIÊN là chỉ số 0
skills[2]; // "JavaScript"
skills[3]; // undefined    — ngoài điểm kết thúc không phải lỗi, chỉ là không có gì
```

Mảng biết chiều dài của chính nó:

```js
skills.length; // 3
skills[skills.length - 1]; // phần tử cuối — "JavaScript"
```

## Thay đổi mảng

```js
const todos = ["learn HTML"];
todos.push("learn CSS"); // thêm vào CUỐI → độ dài 2
todos.pop(); // bỏ khỏi CUỐI → trở lại 1
```

## Các phương thức chủ lực

Mỗi cái nhận một hàm và dựng một **mảng mới** — bản gốc không bị đụng đến:

```js
const scores = [90, 72, 88];

scores.map((s) => s * 2); // [180, 144, 176] — biến đổi từng phần tử
scores.filter((s) => s >= 80); // [90, 88]        — giữ lại các phần tử vượt qua
scores.find((s) => s < 80); // 72              — khớp đầu tiên (hoặc undefined)
scores.includes(88); // true
scores.forEach((s) => console.log(s)); // chạy hàm cho từng phần tử, không trả gì về
```

Đọc `map` là _"mỗi phần tử cũ cho ra một phần tử mới"_ và `filter` là _"giữ những cái vượt qua"_. Hai hàm này bao phủ phần lớn việc xử lý danh sách bạn sẽ làm trong module này.

## Lặp một mảng — mẫu kinh điển

```js
const names = ["Ada", "Grace", "Linus"];

for (let i = 0; i < names.length; i++) {
  console.log(i + ": " + names[i]);
}
```

Bắt đầu từ 0, tiếp tục trong khi `i < names.length`. (Sau này: `for...of` và `forEach` rút gọn điều này — nhưng hãy đọc và viết mẫu kinh điển một cách thành thạo trước.)

## Bạn đã học được gì

- Mảng: danh sách có thứ tự; chỉ số từ **0**; `.length`
- `push`/`pop` thêm/xóa ở cuối
- `map`, `filter`, `find`, `includes`, `forEach`
- Vòng lặp chỉ số kinh điển trên `.length`

**Tiếp theo:** object — dữ liệu có nhãn.
