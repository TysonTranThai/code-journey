Một **biến (variable)** là một chiếc hộp có tên dùng để chứa một giá trị. Thay vì lặp lại dữ liệu, bạn lưu nó một lần rồi tham chiếu bằng tên.

## Khai báo biến

```js
const courseName = "Web Development Beginner";
let lessonsDone = 0;

lessonsDone = 1; // let — giá trị có thể thay đổi
```

- `const` khai báo một biến **không thể gán lại**.
- `let` khai báo biến có thể gán lại.

## Mặc định chuyên nghiệp: const

Dùng `const` cho mọi thứ, và chỉ chuyển sang `let` khi bạn thực sự gán lại. Điều này làm code tự mô tả: khi người đọc thấy `const`, họ biết giá trị không bao giờ lật ngược sau lưng mình.

```js
const price = 19.99;
let total = 0;

total = price * 2; // ổn — total là let
price = 9.99; // TypeError! const không thể gán lại
```

## Tên gọi quan trọng

Tên viết thường, mang tính mô tả, và dùng **camelCase** (từ đầu viết thường, các từ sau viết hoa chữ đầu):

```js
const firstName = "Ada"; // tốt
const x = "Ada"; // hợp lệ nhưng vô nghĩa
const first_name = "Ada"; // hợp lệ nhưng không phải quy ước của JS
```

## Sử dụng biến

Sau khi khai báo, tên _chính là_ giá trị:

```js
const learner = "Ada";
console.log("Hello, " + learner + "!"); // Hello, Ada!
console.log(`Hello, ${learner}!`); // Hello, Ada!  ← template literal
```

Dòng thứ hai là một **template literal**: dấu backtick bao quanh văn bản, với các khe `${ ... }` thả giá trị biến thẳng vào chuỗi. Bạn sẽ dùng chúng liên tục.

## Bạn đã học được gì

- Biến là các giá trị có tên: `const` (mặc định) và `let` (gán lại được)
- Tên camelCase mô tả giá trị
- Template literal: khe `${variable}` bên trong chuỗi backtick

**Tiếp theo:** các loại giá trị mà biến có thể chứa.
