Đến lúc này, mọi dòng code của bạn đều chạy. **Câu lệnh điều kiện (conditional)** cho phép chương trình biết chọn lựa.

## if / else if / else

```js
const score = 87;

if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
} else if (score >= 70) {
  console.log("C");
} else {
  console.log("Keep practicing");
}
```

Các điều kiện được kiểm tra từ trên xuống; nhánh đúng **đầu tiên** thắng và phần còn lại bị bỏ qua. `else` cuối cùng hứng tất cả những gì các nhánh trước bỏ sót.

## Truthiness

Điều kiện không cần là boolean — JavaScript tự chuyển đổi:

- **Falsy:** `false`, `0`, `""` (chuỗi rỗng), `null`, `undefined`, `NaN`
- **Truthy:** mọi thứ còn lại — bao gồm cả `"0"`, `"false"`, và `[]`

```js
const name = ""; // falsy!

if (name) {
  console.log("Hello, " + name);
} else {
  console.log("Please enter your name");
}
```

Mẫu này — _nếu giá trị tồn tại, dùng nó, nếu không thì xử lý trường hợp thiếu_ — có mặt khắp nơi trong code thật.

## Lồng ghép và kết hợp

```js
const age = 15;
const withAdult = true;

if (age >= 18 || withAdult) {
  console.log("You can enter");
} else {
  console.log("Sorry, adults only");
}
```

Hãy ưu tiên kết hợp điều kiện bằng `&&`/`||` thay vì lồng sâu — phẳng dễ đọc hơn.

## Bạn đã học được gì

- `if` / `else if` / `else`: nhánh khớp đầu tiên thắng
- Các giá trị falsy: `false, 0, "", null, undefined, NaN`
- Kết hợp điều kiện bằng toán tử logic thay vì lồng sâu

**Tiếp theo:** làm việc lặp đi lặp lại — vòng lặp.
