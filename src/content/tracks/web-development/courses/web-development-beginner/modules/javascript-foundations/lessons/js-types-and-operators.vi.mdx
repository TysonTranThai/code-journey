Mọi giá trị trong JavaScript đều có một **kiểu (type)**. Sáu kiểu bao phủ phần lớn code của người mới.

## Các kiểu nguyên thủy

```js
const name = "Ada"; // string — văn bản trong dấu ngoặc kép
const year = 2026; // number — cả số nguyên lẫn số thập phân
const pi = 3.14159; // cũng là number
const isLive = true; // boolean — true hoặc false
let nothing = null; // null — chủ động "không có giá trị"
let notSet; // undefined — đã khai báo, chưa bao giờ gán
```

`null` và `undefined` đều nghĩa là "không có gì ở đây" — khác biệt là ai làm điều đó: `null` là lựa chọn có chủ đích của lập trình viên; `undefined` nghĩa là giá trị chưa bao giờ được đặt.

## Số và số học

```js
const price = 19.99;
const quantity = 3;

price * quantity; // 59.97  (phép nhân)
10 + 3; // 13
10 / 4; // 2.5
10 % 3; // 1   số dư — "% là toán tử số dư"
```

`%` (số dư) hữu dụng bất ngờ: `n % 2 === 0` kiểm tra xem một số có chẵn hay không.

## Chuỗi: nối và dựng

```js
const first = "Ada";
const last = "Lovelace";

first +
  " " +
  last // "Ada Lovelace" — + nối các chuỗi
  `Full name: ${first} ${last}`; // template literal (backtick)
first.length; // 3 — chuỗi cũng có thuộc tính
name.toUpperCase(); // "ADA" — và cả phương thức
```

## So sánh → boolean

```js
const age = 20;

age >= 18; // true
age === 20; // true  — so sánh nghiêm ngặt (ba dấu bằng: luôn dùng cái này)
age !== 21; // true  — khác biệt nghiêm ngặt
```

**Luôn dùng `===` và `!==`.** Các phiên bản lỏng lẻo (`==`) thực hiện chuyển kiểu gây bất ngờ — nguồn bug kinh điển mà bạn sẽ không bao giờ cần đến.

## Logic: &&, ||, !

```js
const age = 20;
const hasTicket = true;

age >= 18 && hasTicket; // true — AND: cả hai phía phải đúng
age < 12 || age > 65; // false — OR: ít nhất một phía đúng
!hasTicket; // false — NOT: lật ngược boolean
```

## Bạn đã học được gì

- Sáu kiểu nguyên thủy; null (chủ đích) vs undefined (chưa đặt)
- Số học bao gồm số dư `%`
- Template literal dựng chuỗi; `===`/`!==` cho so sánh
- `&&`, `||`, `!` kết hợp các boolean

**Tiếp theo:** các chương trình biết quyết định và lặp lại.
