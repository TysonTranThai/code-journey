A checkpoint is different from a lesson: nothing new is taught. This is where you prove
the module's ideas are yours. Work through the challenge below **without re-reading the
lessons first** — struggling honestly is the point. The challenge mixes four kinds of
thinking:

1. **Fix** — broken markup that *looks* fine in a browser but is subtly wrong.
2. **Predict** — read code and say what the browser will do before testing it.
3. **Build** — a tiny page from requirements only.
4. **Accessibility judgment** — choose the markup that serves every visitor.

If a test fails and you cannot see why within a few minutes: that is the signal to go
back and re-read the *specific* lesson it comes from, not to guess faster. The test
hints tell you which concept each failure belongs to.

When all tests pass, take a moment to notice what you could not do four lessons ago.
That gap is the course working.
