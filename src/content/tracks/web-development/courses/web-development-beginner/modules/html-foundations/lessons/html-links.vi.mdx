Liên kết — **anchor** — là thứ làm cho web trở thành một _mạng web_: một trang trỏ đến trang khác, rồi trang khác nữa, mãi mãi.

## Phần tử anchor

```html
<a href="https://developer.mozilla.org">MDN Web Docs</a>
```

`href` (**hypertext reference**) cho biết liên kết đi đến đâu; nội dung của phần tử là thứ người truy cập bấm vào.

## URL tuyệt đối so với tương đối

```html
<a href="https://example.com/page">Tuyệt đối — địa chỉ đầy đủ</a>
<a href="about.html">Tương đối — so với trang hiện tại</a>
<a href="#top">Fragment — nhảy đến một id trên chính trang này</a>
```

Dùng URL tuyệt đối cho các trang của site khác, URL tương đối cho các trang trong dự án của bạn. Fragment (`#top`) cuộn đến phần tử có `id="top"`.

## Liên kết mở trong tab mới

```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer"> External site </a>
```

`target="_blank"` mở một tab mới. Khi làm vậy, luôn thêm `rel="noopener noreferrer"` — đó là một thói quen bảo mật (trang được mở không thể thao túng trang đã mở nó).

## Viết văn bản liên kết tốt

Xấu: `<a href="more.html">click here</a>`
Tốt: `<a href="more.html">Read more about HTML elements</a>`

Người dùng trình đọc màn hình thường nhảy từ liên kết sang liên kết mà không có ngữ cảnh — "click here" không cho họ biết gì cả. Hãy mô tả điểm đến.

## Bạn đã học được gì

- `<a href="...">` tạo một liên kết; nội dung là phần có thể bấm
- URL tuyệt đối so với tương đối so với fragment
- `target="_blank"` đi cặp với `rel="noopener noreferrer"`
- Văn bản liên kết nên mô tả điểm đến
