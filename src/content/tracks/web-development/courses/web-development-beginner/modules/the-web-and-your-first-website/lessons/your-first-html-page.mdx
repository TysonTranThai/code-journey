No templates, no generators — in this lesson you write a real HTML document and every
single line in it will be something you can explain.

## The smallest complete page

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, world</h1>
    <p>This page was written by hand.</p>
  </body>
</html>
```

Line by line:

- `<!DOCTYPE html>` — the *document type declaration*. It is not an element; it tells the
  browser "this is a modern HTML document, use the modern rendering rules". Every page
  you write starts with it.
- `<html lang="en">` — the **root element**. Everything else lives inside it. `lang` says
  what language the page is in — screen readers use it to pick the right voice, and
  translation tools use it to decide whether to offer translation.
- `<head>` — information *about* the page. Nothing in here renders on the page itself.
- `<meta charset="UTF-8" />` — the character encoding, so symbols like `é` and `你好`
  render correctly. Put it first in the head, always.
- `<title>` — the page's name: it appears in the browser tab and as the link text in
  search results. Also announced as the page name by screen readers.
- `<body>` — everything the visitor actually sees.

## Nesting is the whole game

HTML is elements inside elements inside elements. `<h1>` sits inside `<body>`, which
sits inside `<html>`. Indentation does not change what the browser sees — but consistent
indentation is how *you* keep the structure visible:

```html
<!-- easy to read: matching indentation for each level -->
<body>
  <h1>Welcome</h1>
  <p>Short and clear.</p>
</body>
```

If you open an element, close it. A missing `</p>` will not crash anything — the browser
guesses, sometimes wrongly, which is exactly the kind of bug you do not want.

## The elements you have so far

- `<h1>`–`<h6>`: headings, most to least important. Use **one `<h1>`** per page — the
  page's main topic — and step down without skipping levels.
- `<p>`: a paragraph. Browsers add sensible spacing between paragraphs automatically.

## Try it now

Open a text editor, copy the smallest complete page, change the `<title>` and the
`<h1>` text to something of yours, save it as `index.html`, and double-click the file.
It opens in your browser — that file *is* a website. (Why `index.html`? Servers serve
`index.html` by default when a visitor asks for a folder — a convention worth keeping.)

## What you learned

- `<!DOCTYPE html>`, `<html lang>`, `<head>`, `<meta charset>`, `<title>`, `<body>` —
  and what each is for
- Nesting and indentation as readability
- `<h1>`–`<h6>` with one `<h1>` per page; `<p>` for paragraphs
- A saved `.html` file is already a working page
