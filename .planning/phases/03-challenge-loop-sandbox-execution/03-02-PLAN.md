    3. `src/workers/sandbox.ts` (server-only): `runSandbox(payload, onEvent)` builds `docker run --rm --network none --read-only --tmpfs /tmp:size=16m:rw,noexec,nosuid --memory 256m --memory-swap 256m --cpus 0.5 --pids-limit 64 --cap-drop ALL --security-opt no-new-privileges --user 1000:1000 -v <jobdir>:/workspace:ro codejourney-sandbox:latest node /workspace/run-tests.mjs` via child_process.execFile (the ONLY exec in the codebase, worker-side). Writes code + tests + a run-tests.mjs harness into a fresh mkdtemp jobdir per run, removed in finally. Harness: imports each test file, catches per-test errors, prints a JSON line `__CJ_RESULT__ {json}` with PerTestResult[].
    4. Parse the `__CJ_RESULT__` line from output into VerdictPayload (verdict passed if all tests passed, failed otherwise; timeout; error on harness crash).
