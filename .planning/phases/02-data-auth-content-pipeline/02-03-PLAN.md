       References in course/module/lesson arrays are `{ reference: "<sibling-id>" }` so ordering is explicit and ids stay unique-checkable.
    2. Export inferred types (`type Track = z.infer<typeof trackSchema>` etc.) and a top-level `curriculumSchema` that composes track-level validation.
    3. No new dependencies required — zod 4 is installed.

Expose: `getTracks()`, `getTrack(id)`, `getCourse(trackId, courseId)`, `getModule(trackId, courseId, moduleId)`, `getLesson(trackId, courseId, moduleId, lessonId)`, `getLinearLessons(trackId)` (flattened track order across modules), `getLinearNeighbors(trackId, lessonId)` → `{ prev, next } | { prev: null, next: null }`.
    4. Throw typed `CurriculumNotFoundError` for missing ids (pages will call `notFound()`).
  </action>
