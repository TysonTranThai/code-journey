## Modules (20)

1. object-model — value categories, storage duration/lifetime, initialization subtleties
2. move-forwarding — forwarding refs/collapsing, guaranteed elision, noexcept moves, Rule of Zero/Five
3. templates-deep — specialization, variadics/folds, if constexpr, NTTPs, CTAD
4. concepts — requires-expressions, ad-hoc constraints, subsumption, diagnostics
5. compile-time — constexpr/consteval/constinit, type traits, integral_constant
6. ranges-views — pipelines, projections, custom stride view, dangling hazards
7. coroutines — promise_type from primitives, generator<T>, lifetime hazards
8. memory-model — data races, happens-before, atomics, ordering selection
9. concurrency — jthread/stop_token, mutex/CV/futures, bounded queues, pipeline stages
10. memory-allocators — allocation costs, pool free-lists, std::pmr arenas, data-oriented design
11. performance — allocation counting, algorithmic wins, hot-path discipline (deterministic graded metrics)
12. ub-defensive — UB taxonomy by class, defensive boundaries, sanitizer thinking
13. debugging — debugger discipline, crash forensics, minimal repros, incident repair
14. testing — property-based round-trips, mutation-killing test batteries, fuzzer-style inputs
15. build-systems — configuration space, feature-test macros, hardened flags (single-TU gradeable core)
16. abi-linking — API vs ABI, layout stability, pimpl, extern "C" opaque factories
17. networking — framing/decoders, request parsing, backpressure (protocol layer, sandbox-gradeable)
18. security — overflow-checked arithmetic, path canonicalization, injection-safe quoting, hardening
19. architecture-production — event bus, layered config, token bucket, boundaries & inversion
20. capstone-hpc-service — integrated admission core + ops report + ship-gate acceptance battery

Deliberate scope cuts (documented in docs/CURRICULUM-RESEARCH-CPP-ADVANCED.md):
lock-free reclamation (ABA/hazard pointers) and raw sockets are taught as
concepts/protocol-layer only — the single-TU sandbox cannot grade race timing,
CAS loops, or socket I/O, so they are graded deterministically or left to prose.
