# Plan 07-11: Private Beta Verification Gate + Docs Refresh

## Objective

Run the full verification suite that proves the beta gate, then refresh the security,
accessibility, and production docs to reflect reality. No claims beyond what the verified
suite demonstrates.

## Threat → behavior

- **Threat:** the milestone claimed green but the audit surfaced P0 blockers. Beta must be
  gated on the fixes being real and regression-covered.
- **Existing behavior (verified baseline):** 94/94 unit/integration, 13/13 E2E, audit clean,
  build clean — plus the audited P0/P1 issues.
- **New behavior:** a single gate run proves the beta target: register → login → browse →
  lesson → challenge → run → trustworthy verdict → progress → mentor → discuss, on desktop,
  tablet, and mobile, without the known P0 blockers.

## Gate checklist (all must pass)

1. **Grade integrity** (07-01): malicious-delimiter regression green; real pass/fail unaffected.
2. **Submission authz** (07-02): anonymous run → 401; owner read OK; cross-user → 404.
3. **Rate limiting** (07-03): 429 + Retry-After on register/login/reset/run; mentor atomic.
4. **Password reset** (07-04): mocked email transport test green; enumeration-safe response.
5. **Copy** (07-05): stale-messaging guard green; no false "upcoming phases" copy.
6. **Mobile editor** (07-06): editor non-zero, paints, accepts input, preserves draft, runs,
   shows verdict — at 1440/1280/1024/768/430/390/375.
7. **Mobile run flow** (07-07): persistent Run reachable from Code/Output.
8. **Static public** (07-08): public routes static (○); protected routes dynamic; anonymous
   reads public content; signed-in header intact.
9. **Breadcrumb/prompt** (07-09): titles shown, inline-code renders, no injection.
