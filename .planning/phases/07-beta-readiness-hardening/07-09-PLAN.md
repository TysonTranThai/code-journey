# Plan 07-09: Breadcrumb Titles + Prompt Inline-Code Rendering

## Objective

Fix two content-presentation defects on the challenge page: (1) the breadcrumb shows the
course **slug** instead of the human-readable title, and (2) challenge prompts render literal
backticks such as `` `My First Page` `` instead of inline code.

## Threat → behavior

- **Defect 1 (breadcrumb):** the challenge page breadcrumb uses `label: courseId`
  (`web-development-foundations`) for the course crumb and omits the module. Verified in
  `src/app/(learn)/learn/[trackId]/[courseId]/[moduleId]/[lessonId]/challenge/[challengeId]/page.tsx`
  (`Breadcrumbs` items array).
- **Defect 2 (prompt):** the prompt string (e.g. "Keep the text `My First Page` unchanged.")
  is rendered in a `<p className="whitespace-pre-wrap">{prompt}</p>` in
  `ChallengeWorkspace.tsx`, so backticks appear literally.

## Design decisions

- **Breadcrumb:** use content metadata from the loaders — `getCourse(trackId, courseId)` for
  the course title, and (recommended) the module title via the module's reference. Add a
  `getModule(trackId, courseId, moduleId)` loader accessor if one doesn't exist (small,
  consistent with existing loaders). Path: Learn / Track / Course / Module / Lesson / Challenge.
- **Prompt inline-code:** render the prompt as lightweight inline markdown for inline code
  only — replace `` `code` `` spans with styled `<code>` elements, and escape everything else.
  This is safe (we never inject raw HTML; the code content is escaped) and deterministic. It
  keeps stored prompts as plain strings (no content migration) while fixing the visual defect.
  The prompt is authored content (trusted, renderer-controlled), so a small inline parser is
  appropriate; do **not** remove backticks globally.

## Current implementation

- Breadcrumb items include `{ label: courseId, ... }` (slug) and skip the module.
- `ChallengeWorkspace` renders `prompt` as a plain `<p>`.

## Files likely affected

- `src/app/(learn)/learn/[trackId]/[courseId]/[moduleId]/[lessonId]/challenge/[challengeId]/page.tsx`
  — build breadcrumb from loader metadata (course/module titles), or pass them into the
  workspace.
- `src/components/learn/Breadcrumbs.tsx` — no change unless item shape is extended; the fix is
  in the caller passing correct labels.
- `src/components/challenge/ChallengeWorkspace.tsx` — replace the plain `<p>{prompt}</p>` with
  an inline-code renderer.
- `src/lib/curriculum/loaders.ts` — add `getModule(...)` if missing.
- `tests/e2e/breadcrumb-prompt.spec.ts` (new).

## Implementation steps

1. Add `getModule(trackId, courseId, moduleId)` to `loaders.ts` (returns the module; throws if
   missing) — mirroring `getCourse`/`getLesson`.
2. In the challenge page, resolve `course = getCourse(trackId, courseId)` and
   `module = getModule(trackId, courseId, moduleId)` and use `course.title` / `module.title` in
   the breadcrumb items (keep the current Track + titles pattern).
3. Add a tiny `renderInlineCode(text)` helper in `ChallengeWorkspace` that escapes HTML and
   wraps `` `…` `` runs in `<code>`. Escape all other text.
4. Render `prompt` through that helper (keeping `whitespace-pre-wrap` for line breaks).
5. Confirm course/module titles appear and backticks render as inline code.

## Tests

- `tests/e2e/breadcrumb-prompt.spec.ts`: on the challenge page, assert the breadcrumb contains
  the course title `Web Development Foundations` (not the slug `web-development-foundations`)
  and the module title; assert the prompt shows a `<code>` element containing `My First Page`
  and no literal backtick characters in the visible text.

## Rollback

Content/metadata changes only; reverting restores the slug crumb and plain-text prompt. No
schema/data migration.

## Security implications

The inline-code renderer must HTML-escape all non-code text and the code content (no raw
`dangerouslySetInnerHTML`). Verified pattern: exercise an authored prompt containing `<`,
`>`, `&` and a backtick to confirm it renders escaped with no markup injection. Keeps the
existing no-`dangerouslySetInnerHTML` guarantee.
